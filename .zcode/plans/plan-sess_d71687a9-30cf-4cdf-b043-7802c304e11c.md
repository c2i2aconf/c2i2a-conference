# C2I2A site: fix what's broken + efficiency pass

Audit result: `tsc` and `lint` are clean; all pages use the Payload Local API and are prerendered. The work below is phased bug fixes → production blockers → caching → performance → hygiene. **No schema changes → no new migration needed** (only admin config, components, and libs change).

## Phase 1 — Critical bugs

1. **Registration form fails for every anonymous visitor** (`src/lib/actions/register.ts:31`): the duplicate-email `payload.find` on `registrations` runs without `overrideAccess` while the collection's read access is admin/self-only → Payload throws `Forbidden` → outer catch returns `server_error`. Add `overrideAccess: true` (internal existence check only; no docs are returned to the caller — same pattern `auth.ts` already uses for MagicLinks).
2. **Homepage stats always 0/0/0** (`src/lib/queries.ts:250`): same cause in `getEditionStats` — the registrations count throws for anonymous renders and the catch zeroes everything. Add `overrideAccess: true` to that one `find` (speakers/sessions counts are public and stay as-is).
3. **Dev login impossible without `RESEND_API_KEY`** (`src/lib/actions/auth.ts:133-145`): the `devLink` fallback relies on `sendEmail` throwing, but with no adapter Payload silently uses the console adapter which never throws. Detect explicitly: if `!process.env.RESEND_API_KEY` and not production, still call `sendEmail` (console logging) but also `console.log` the link and return `{ success: true, devLink: link }`.
4. **Editions admin list** (`src/collections/Editions.ts:15`): `defaultColumns` still references `status`, renamed to `editionStatus` — fix the column name.
5. **ProgramSchedule** (`src/components/sections/ProgramSchedule.tsx`):
   - Fix inverted left-border logic (line ~103): typed sessions currently get *no* border color; only logistics/tour do. Apply the type color when present.
   - Replace hardcoded `'Session'` fallback (~117) with a translated string passed from the server page.
   - Fix date-tab hydration/timezone risk (~82): `new Date(date).toLocaleDateString()` in a client component renders differently server vs browser west of UTC. Pre-format tab labels on the server and pass them as props.
6. **UTC-safe date rendering**: add a small `formatDate` util (append `T00:00:00Z`, format with `timeZone: 'UTC'`) for date-only fields (home sessions, `dates/page.tsx`, `about/page.tsx`) so day-only values never shift a day.
7. **i18n hardcoded English**: "Keynote" badge (`speakers/page.tsx`, home speakers section), sr-only "Toggle theme"/"Toggle language" → message keys in `messages/fr.json` + `en.json`.
8. **Minor**: sponsors with no website render `href="#"` → render a non-link card; `getCommittees` limit 10 → 100; `getLiveEdition` gets deterministic `sort: '-startDate'`.

## Phase 2 — Make production media work

9. **`src/lib/private-vercel-blob.ts` `generateURL`**: it returns raw `https://{storeId}.private.blob.vercel-storage.com/...` URLs, which `next/image` rejects (no `remotePatterns` in `next.config.ts`) and which require auth → all CMS images break on deploy. Change `generateURL` to return the Payload static route per collection (`/api/media/file/...`, `/api/submission-files/file/...`, including doc prefix) so files flow through the access-checked `staticHandler` — matching the `localPatterns` entry already in `next.config.ts`. Blob keys are unchanged.
10. **Cache-Control split**: the staticHandler sets `private, max-age=3600` for everything, defeating CDN caching. Serve `media` responses with `public, max-age=3600` (publicly readable content collection, ETag/304 preserved); `submission-files` stay `private`.
11. **Use generated size variants**: `Media.ts` already generates `thumbnail/card/hero` sizes that no page uses — add a `getMediaVariant(media, size)` helper and use `card`/`thumbnail` in speaker grids, gallery, sponsors; hero keeps `hero`/full.
12. After deploy, existing docs that stored absolute blob URLs need a re-save or one-off normalization — noted as a deploy checklist item.

## Phase 3 — Hybrid caching (ISR + on-demand revalidation)

13. **ISR fallback**: `export const revalidate = 3600` on all content pages (`/`, about, speakers, program, dates, sponsors, committees, gallery, archive, `archive/[year]`, `p/[slug]`, access, contact, registration). Do **not** touch `submission`, `account`, `auth/*` (genuinely per-request). Side benefit: DB-less dev builds now retry hourly instead of being frozen.
14. **On-demand invalidation**: shared helper (`src/hooks/revalidateSite.ts`) calling `revalidatePath('/', 'layout')` (invalidates all locale subtrees) wired as `afterChange`/`afterDelete` hooks on Editions, Pages, Speakers, Sessions, ImportantDates, Sponsors, Committees, GalleryItems, Media, and `afterChange` on the SiteSettings global. Admin edits appear within seconds; hourly ISR is the safety net.

## Phase 4 — Efficiency

15. **Request-level dedupe**: wrap `getSiteSettings`, `getLiveEdition`, `getNavigationPages` in React `cache()` — collapses the 2-4× repeats across `generateMetadata` + page body + `Header.tsx:17-18` + `Footer.tsx:18-20` (~18 → ~6 queries on dynamic renders).
16. **Parallelize**: `Footer.tsx` sequential awaits → `Promise.all`; `archive/[year]/page.tsx:42-44` sessions/speakers/gallery → `Promise.all`; Header nav fetch folded in where the edition-id dependency allows.
17. **Trim over-fetching**: add `select` to `getNavigationPages` (title/slug/navOrder only); map sessions down to needed fields (id, title, type, times, room name, speaker names) before passing to the `ProgramSchedule` client component instead of serializing full depth-2 docs into the RSC payload.
18. **Drop framer-motion**: rewrite `Reveal` and `AnimatedCounter` as small dependency-free client components (IntersectionObserver + CSS transitions/rAF), same props/visual behavior. Removes the heaviest client lib from every page's bundle.
19. **Trim client messages**: `NextIntlClientProvider` (`[locale]/layout.tsx:68`) currently inherits the full catalog client-side. Audit which namespaces client components actually use (forms, MobileMenu, toggles) and pass only those.
20. **`loading.tsx`** for the `[locale]` segment using the currently-dead `skeleton.tsx`, so dynamic routes (`/submission`, `/account`, `/auth/login`) stream a shell.
