# Surgical Vercel reset: recreate the project, keep everything else

**Kept untouched:** the Neon database (all site content), the GitHub repo (all code), and the Vercel blob store (media files — the token stays the same).

**Step 0 — you (30 sec, only you can see this):** open the Vercel dashboard → Overview and Billing, and check your inbox for an email from Vercel about **account verification**. Builds that silently never start on a young team are most often a verification hold. If you find one, completing it may fix deploys without any reset — tell me and I'll simply redeploy.

Then, if no banner or after verifying:

1. **Back up env vars**: `npx vercel env pull .env.vercel-backup --environment=production` (stays local and gitignored; contains DATABASE_URL, PAYLOAD_SECRET, RESEND_API_KEY, BLOB_READ_WRITE_TOKEN, EMAIL_FROM, NEXT_PUBLIC_SERVER_URL).
2. **Delete only the project**: `npx vercel project rm c2i2a-conference --yes` (all deployments gone — they're all broken or outdated anyway).
3. **Recreate it**: `npx vercel project add c2i2a-conference` then `npx vercel link --project c2i2a-conference --yes`. Build settings come from the repo's `vercel.json` (`npm run ci`); framework auto-detects as Next.js.
4. **Restore env vars** from the backup for Production (and Preview) via `vercel env add`.
5. **Reconnect GitHub**: `npx vercel git connect https://github.com/c2i2aconf/c2i2a-conference`.
6. **Deploy and watch**: trigger via empty commit push, poll `vercel inspect` — this time confirm the build actually starts and reaches Ready (~1–2 min, matching yesterday's successful builds).
7. **Verify**: production alias serves the deployment; smoke-check `/`, `/fr`, `/admin` return sane statuses (302 to SSO while protection is on).
8. **If builds still never start on the fresh project**: it's account-level, not project-level — you'd contact Vercel support / complete whatever verification they ask for, and the code/DB side needs zero changes.

**Not needed:** deleting the Neon project, the GitHub repo, or the Vercel account/team.
